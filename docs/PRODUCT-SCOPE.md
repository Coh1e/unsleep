# Unsleep 极简产品范围

日期：2026-10-24。状态：人类已最终确认整体范围，作为 Unsleep 首版产品基线。来源：grill-me / grilling 访谈及最终整体确认。本文记录产品决策，不代表已实现，也不构成恢复开发授权。

## 定位

独立的 Windows 托盘防休眠工具，正式放弃 Caffeine 行为及参数兼容。主要支持下载、编译、计算、备份等后台任务，兼顾阅读和演示时的屏幕常亮。macOS 与 Linux 同类应用仅作设计参考。

## 启停与界面

- 手动启动程序即开启防休眠，默认允许息屏、持续时间不限。
- 程序留在托盘；手动停止、倒计时结束、低电量停止均结束本次使用，程序不退出。
- 原生菜单仅包含：防休眠（开关）、保持屏幕常亮、持续时间、电池保护、退出。
- 左右键打开相同菜单，无双击隐藏操作；无独立状态窗口或自绘悬浮面板。
- 图标采用人类选定的 GPT 咖啡杯方案：蒸汽表示运行，冷杯表示停止；屏幕与时钟角标体现本次常亮和有限计时，虚线屏幕表示常亮已勾选但暂缓。应用图标使用不带配置角标的基础咖啡杯。普通悬浮提示显示实际状态、剩余时间或停止原因，并同步完整勾选配置及电池阈值。
- 低电量自动停止、系统请求失败时通知一次；普通启停与倒计时结束不弹通知。
- 退出释放本工具的电源请求。停止仅恢复系统正常电源管理，不主动触发休眠。

## 持续时间与记忆

- 持续时间：不限时、30 分钟、1 小时、2 小时；无自定义输入和指定日期时间。
- 切换时长从当下重新计时，到期停止防休眠并留在托盘。
- 仅记忆电量阈值；不恢复旧倒计时。
- 屏幕常亮仅作用于本次开启，停止后重置；每次启动默认允许息屏、持续时间不限。

## 电池与系统边界

- 电池保护默认 20%，可选 10%、20%、30%，记忆选择。
- 未插电且电量达到或低于阈值，结束本次防休眠，同时释放屏幕常亮请求。
- 不提供绕过低电量保护的选项；插电不自动恢复，需手动重新开启。
- 锁屏时继续请求系统保持唤醒，允许屏幕关闭，不阻止锁屏。
- 合盖遵循 Windows 设置，不提供合盖防休眠功能。
- 尊重手动休眠，重新唤醒后本次防休眠保持停止。
- 部分 Modern Standby 设备对电池供电且屏幕关闭时的电源请求有限制，产品不能承诺所有设备都持续运行；后续必须实机验收。

## 首版排除

模拟输入、Caffeine 参数兼容、开机自启、快捷键、命令行控制、每日计划、延迟开启、应用或 CPU 监测、合盖防休眠、阻止锁屏、自绘窗口、外观选择。

保留必要可靠性措施：资源管理、单实例、Explorer 重启后的托盘恢复、失败反馈、许可证及资源来源说明。KISS 不以减少这些措施为目标。
