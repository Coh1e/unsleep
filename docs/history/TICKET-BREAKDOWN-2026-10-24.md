# Unsleep 实施任务拆分

日期：2026-10-24。本地依据 [实施规格](../IMPLEMENTATION-SPEC.md) 修订项目本地化门槛。此前记录 T01—T12 已发布为 Issues #2—#13，规格父票为 [Issue #1](https://github.com/Coh1e/unsleep/issues/1)；T01 已验收关闭。本轮未回读远端，Issue 正文尚待同步。业务继续暂停，仅文档整理与工作流配置验证可继续；当前授权与验证以 [交接](../../HANDOFF.md) 为准。

## 通用约定

ChatGPT 规划、调度和验收；唯一 OpenPi 使用 DeepSeek 编码、构建、测试和修复。人类提供必要主机能力并决定恢复与发布。只复用项目专用配置和现有工具，优先 CLI，不预建 RPC 服务。不新增执行代理。

保留既有 T01—T12 编号与依赖结构，按现行工作流修订 T02—T05 的目标，不因取消沙箱要求自动关闭任务。业务票仍须通过接入、项目本地化、CLI 任务—报告闭环、目标平台与人类恢复授权准入。环境不使用 WSL；不授权主机组件安装或项目外写入。

每票预期执行报告统一包含：任务标识、状态、代码/配置版本、允许范围、差异、实际命令及退出码、验收逐项结论、脱敏证据位置、失败与未验证项、交接及下一步。历史结果、静态检查、本轮运行和未运行分别列出；不得将模型自述作为唯一证据。以下每票另列专属报告内容。涉及代码的票同时完成该切片的核心行为测试与 Windows 集成验证，不把测试统一推迟到最后。

## 任务定义

### T01 核验 OpenPi + DeepSeek 项目接入

- 依赖：无任务依赖；执行须获得对应环境验证授权。
- 目标与范围：复用已安装 Pi 和项目专用配置，核验无工具任务下发及严格 JSON 报告闭环，不重复搭建、不开放工具。
- 验收：记录版本及项目内运行数据位置；任务标识/nonce匹配、严格JSON、空差异/命令、无工具事件及正确退出结果；凭据不泄露不入库，只有子进程局部环境设置；区分此前通过与本次结果。
- 专属报告：接入清单、脱敏事件核对、JSON验收结论及费用未核对事项。

### T02 核对项目本地化配置

- 依赖：无任务依赖；在工作流配置验证范围内执行。
- 目标与范围：核对 OpenPi 的安装、配置、依赖、缓存、临时文件、日志和运行数据均项目本地化；按实际需要配置项目内 rea，不为业务暂停期间开展逆向。优先已有运行时与 CLI。
- 验收：记录工具及配置路径、数据目录、子进程局部环境与凭据保护；缺少工具或路径尚未确认时明确列出，不记为通过。不引入沙箱、WSL 或全局安装。
- 专属报告：本地化清单、配置与忽略规则检查、未确认位置及下一步。

### T03 验证执行工具与子进程的数据位置

- 依赖：T01、T02。
- 目标与范围：将无业务修改的小任务交给 OpenPi，在项目内验证区按需启用执行工具，核对工具和子进程实际文件与数据位置；任务文本、产物和报告不含真实密钥。
- 验收：实际工具事件、命令、退出结果及文件差异可核对；配置加载和子进程缓存/临时文件/日志位置符合 T02 清单；未知位置标记未验证。不试写项目外位置，不要求证明系统强制拒绝越界。
- 专属报告：工具与子进程执行证据、路径核对及未验证项；不得宣称通过操作系统级隔离。

### T04 完成最小 CLI 任务—报告闭环

- 依赖：T03。
- 目标与范围：复用现有 CLI 完成结构化任务下发与报告收集；不强制编写桥接，需要新增实现时交唯一 OpenPi，不预建服务或 RPC。
- 验收：任务含标识、目标、工作目录、输入、允许修改范围、约束和验收标准；完成验证区内一次无业务改动的小任务；核验失败、超时、格式错误和标识不符时的拒收处理；差异、实际命令与证据可独立核对；遵守 T03 数据位置约定，无密钥进入任务、报告或 Git。
- 专属报告：成功与拒收样例、实际执行差异、CLI 运行证据和 E1 完成情况。

### T05 审查业务实施准入与目标平台

- 依赖：T04；人类明确恢复业务开发是关闭本票的必要条件。
- 目标与范围：ChatGPT核验T01—T04证据并记录人类决定；明确 Windows 版本、发布架构及可用实机，形成首项OpenPi任务。不在此票编写业务代码。
- 验收：接入、本地化和 CLI 执行报告闭环全部接受；支持平台和设备验收安排可执行；恢复业务开发授权有明确记录；当前暂停不能因标签或前票关闭自行解除。
- 专属报告：准入核对表、授权依据、平台矩阵和尚未具备的设备。

### T06 交付安全的托盘启停最小闭环

- 依赖：T05。
- 目标与范围：启动即请求防休眠、默认允许息屏/不限时，原生托盘启停和退出；切换新主流程，移除或禁用旧兼容入口。内含默认20%及未知电池状态的安全门控，避免交付暂时绕过保护的版本；后续票扩展阈值菜单、计时与屏幕能力。
- 验收：手动停止留托盘且释放请求，重开默认值，退出清理；电池低于/等于20%或状态未知时停止/拒绝开启，插电不自动恢复；状态反馈以实际请求结果为准；施加失败停止、释放未确认如实显示、故障通知去重；基本单实例；无模拟输入、旧命令控制或旧计划可触发运行。核心测试与实机请求证据覆盖C1及相关C3/C5/W2。
- 专属报告：启动/停止/退出/拒绝开启/请求失败证据，旧入口停用清单与资源来源初查。

### T07 交付三档电池保护与唯一持久化设置

- 依赖：T06。
- 目标与范围：电池菜单10%/20%/30%，仅记忆阈值；完整电源事件和最长5秒补查。确定最小应用专属存储方式，不引入通用配置框架。
- 验收：三档阈值前/等于/低于、插拔电、明确无电池、未知来源/电量及运行中改阈值均符合规格；无绕过或自动恢复；无效设置回退20%，写失败保留本次选择并提示未保存；重启不恢复其他会话设置；低电量每次使用至多通知一次。覆盖C3及相关C5/W3/W4。
- 专属报告：电池边界矩阵、事件与补查时延、持久化/错误证据。

### T08 交付本次屏幕常亮及锁屏行为

- 依赖：T06。
- 目标与范围：原生菜单切换本次屏幕常亮；贯通核心、系统请求与会话事件。
- 验收：停止重置屏幕选项；锁屏释放屏幕请求但保留系统请求，解锁仅在本次仍运行且曾选常亮时恢复；不阻止锁屏；失败按通用规则停止和反馈；停止时该控件禁用。覆盖相关C1/C4/C5/W2。
- 专属报告：请求施加/释放、锁定解锁及失败路径证据。

### T09 交付四档持续时间与剩余时间提示

- 依赖：T06。
- 目标与范围：不限时/30分钟/1小时/2小时菜单，贯通单调时间、到期停止、托盘剩余时间反馈。
- 验收：切换从当下重新计时，不限时清截止；墙上时钟/时区变化不影响；截止前/等于/超过、延迟及旧回调正确；正常循环到期延迟目标不超过1秒；到期安静停止留托盘，重开默认不限时；停止时持续时间控件禁用。覆盖C2及相关C1/W1。
- 专属报告：时间边界测试、实机到期及提示证据。

### T10 交付睡眠恢复与交错事件下的可靠停止

- 依赖：T07、T08、T09。
- 目标与范围：贯通睡眠/休眠通知与恢复，统一电池、屏幕、计时和故障的事件优先级及停止原因。
- 验收：睡眠或恢复均停止且不自动重开，漏掉睡前事件也安全；合盖遵循系统，不阻止用户睡眠；按规格优先级处理重复/交错事件，所有停止路径释放请求、重置本次屏幕选项、旧回调不重开；通知不重复，提示实际原因。覆盖C4/C5和跨切片C1/W2回归。
- 专属报告：交错事件矩阵、睡眠/休眠/恢复/合盖实机证据及设备事件限制。

### T11 完成托盘恢复、资源与旧功能收尾

- 依赖：T10。
- 目标与范围：完整五项原生菜单和状态提示，Explorer重启后可继续操作；核查旧功能清除与资源生命周期，不重做已通过切片。
- 验收：左右键一致、无双击隐藏行为、无额外窗口；图标及提示区分运行/停止/原因，勾选与禁用正确；第二实例不改变状态，Explorer重启不重置时长；正常/异常清理无遗留自有请求；所有排除项无可达入口，淘汰相应旧测试；资源来源和许可证明确。覆盖W1及相关W4。
- 专属报告：菜单/托盘恢复演示、资源清理审查、移除清单、许可证核对及必要回归。

### T12 完成首版平台验收与交付证据

- 依赖：T11；需T05约定的实机与平台可用。
- 目标与范围：唯一OpenPi完成声明支持平台的构建和集成验收，ChatGPT按完整矩阵评审；本票不发布产品。发现超出小修复范围的问题时另拆返工票并阻塞本票。
- 验收：E1、C1—C5、W1—W4逐项可追溯，相关支持架构实际构建运行；电池设备和Modern Standby记录型号/设置/供电及限制；缺设备标记未运行，相关验收不算通过且不关闭本票；文档不保证所有设备持续运行；源码/产物版本、许可证与接手说明完整，敏感数据和生成文件不入库；发布仍由人类决定。
- 专属报告：总验收矩阵、平台构建/运行记录、设备限制、剩余风险与交付清单。
